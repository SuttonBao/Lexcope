# Lexcope V1 开发计划

## 产品范围

面向 iPhone / iPad，iOS 17+，中文界面，SwiftUI 原生应用。无需登录，离线使用，本地保存学习进度。V1 包含词集选择、内置生活和学术备考词集、CSV/JSON 导入、极简词卡、详情、系统英语发音、三向滑动评分和每日复习。

默认词卡仅展示单词和音标；点击卡片打开中文、英文解释、例句、词源、搭配、词族。右滑认识，左滑不认识，下滑模糊，同时提供可访问性评分操作。首次学习有操作提示，可撤销最近一次评分。

V1 不包含账户、付费、云同步、OCR、AI 在线释义或官方考试题库。内置词集是起始内容，明确标注完整度和来源；考试名称只描述备考方向。

## 技术与数据决策

- `LexcopeCore`：无第三方依赖的 Swift Package，容纳模型、调度、队列、导入及原子文件存储，可在 macOS 命令行测试。
- `Lexcope`：SwiftUI iOS App，依赖本地 package，AVSpeechSynthesizer 发音，UserNotifications 可选每日提醒。
- JSON 版本化本地存储；写入成功再更新 UI，损坏文件不覆盖，向用户提供重试；导入全量校验后原子提交。
- 已学词进度按词条共享，词集只保存词条引用，避免重叠词集重复学习。
- 新词每日上限默认 20；优先处理到期词，复习不受新词上限限制；每日已学新词数在重启后仍有效。
- 所有自然日计算使用 Calendar，覆盖时区和夏令时边界。

## 复习规则

这是受遗忘曲线启发的间隔重复启发式，并非声称能精确预测个人遗忘概率。

认识：依次安排 1、2、4、7、15、30 天后；完成阶梯后保持每 30 天复习。
不认识：回到第一阶段，5 分钟后重学。
模糊：阶段回退一级，10 分钟后重学。
短时重学不强制用户停留，首页显示下次时间。任何重学后选择认识，至少下一自然日复习。

## 分支与验收

每项从已集成的 main 建立下列分支，完成后单次 commit，再 fast-forward main。分支保留供检查。

1. `feature/v1-plan`：提交本计划、范围和验收条件。
2. `feature/app-foundation`：数据模型、本地持久化、Swift package 和可打开的 Xcode 工程；验证模型往返、损坏数据保护和原子保存。
3. `feature/spaced-repetition`：调度、每日队列、评分和撤销；验证三种评分、跨日、到期优先、每日上限、重启和夏令时。
4. `feature/vocabulary-library`：内置词集与来源说明，CSV/JSON 导入；验证 BOM、引号、多行、重复、必填字段、大小上限及无部分导入。
5. `feature/study-experience`：词卡、详情、点击音标发音、三向滑动、按钮/VoiceOver 替代、撤销和完成状态。
6. `feature/daily-review`：今日首页、词集选择、设置、提醒、场景恢复刷新和学习统计。
7. `chore/v1-validation`：集成测试、macOS/iOS CI、导入样例、运行说明和验收记录。

## 验收清单

- 冷启动可选择内置词集，进入词卡，不预先泄漏释义。
- 点击音标只播放读音，不打开详情；单指点击其他卡片区域展示详情。
- 详情字段缺失时说明尚未提供，不生成未经校验的内容。
- 三向滑动与辅助按钮结果一致；轻触、上滑或小幅拖动不评分。
- 认识、不认识、模糊分别产生正确的下次复习时间；关闭重开不丢进度。
- 多词集重复单词共享学习记录；到期词优先；不通过重开学习会话绕过每日新词额度。
- CSV/JSON 可从“文件”导入，错误能定位问题，不写入半成品。
- 提醒由用户在设置中主动启用，不在首次启动索要权限。
- Swift 核心测试通过；Xcode 工程可解析。iOS 编译、模拟器和真机检查需完整 Xcode 与 SDK，当前机器没有，因此不能宣称已完成运行验收。
