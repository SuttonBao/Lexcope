## iOS 自动验证

`.github/workflows/ci.yml` 配置 macOS runner 执行 iOS 模拟器构建与原生 UI 冒烟测试。UI 测试使用 Debug 专属的 UUID 数据目录，不接触正常用户数据；验证选择词集、音标入口不打开详情、详情开关、右滑/左滑/下滑、撤销、重启后的进度与词集持久化。

本机没有完整 Xcode 或 iOS SDK，因此未在本地执行 iOS 模拟器构建、UI 测试或真机测试。远端执行状态以 GitHub Actions 为准，不将配置测试当作测试已通过。
